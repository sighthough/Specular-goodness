# Specular-goodness
demo of advanced speculars

this speculars take into account the angle the light is hitting the texture and properly 
mix the colour of the texture with the colour of the light to look snazzy as heck
shadows are calculated in their own way too
feel free to rip anything you want from the index file
the effecs is most notable when you lower the specular gloss value (shinyness)

tech demo : [here](https://sighthough.github.io/Specular-goodness/)
